# GrowthPilot 数据字典

## 1. 数据设计说明

GrowthPilot MVP使用两类模拟数据：

1. 销售经营数据：用于计算GMV、毛利、广告效率和库存风险。
2. 用户评价数据：用于识别消费者反馈主题和产品问题。

系统中的重要经营指标由Python计算，大模型只负责解释结果和生成建议。

## 2. 销售经营数据

文件名：`sample_sales.csv`

每一行代表某个SKU在某一天、某个平台上的经营表现。

| 字段名 | 中文含义 | 数据类型 | 示例 | 用途 |
|---|---|---|---|---|
| date | 日期 | 日期 | 2026-08-01 | 按日、周进行趋势分析 |
| platform | 电商平台 | 文本 | Tmall | 比较不同平台表现 |
| sku_id | SKU编号 | 文本 | SKU001 | 唯一识别商品 |
| sku_name | 商品名称 | 文本 | 无糖气泡水青柠味 | 展示分析结果 |
| category | 商品类别 | 文本 | 饮料 | 按品类汇总 |
| unit_price | 商品单价 | 小数 | 6.90 | 计算销售金额 |
| unit_cost | 单位成本 | 小数 | 3.20 | 计算毛利 |
| units_sold | 销售数量 | 整数 | 320 | 判断销量表现 |
| ad_spend | 广告费用 | 小数 | 450.00 | 计算广告效率 |
| impressions | 广告曝光量 | 整数 | 25000 | 计算点击率 |
| clicks | 广告点击量 | 整数 | 850 | 计算点击率和转化率 |
| orders | 订单数量 | 整数 | 280 | 计算客单和转化 |
| stock | 当前库存 | 整数 | 1200 | 判断缺货或积压风险 |
| returns | 退货数量 | 整数 | 12 | 计算退货率 |
| promotion_flag | 是否促销 | 布尔值 | true | 解释销量变化 |

## 3. 用户评价数据

文件名：`sample_reviews.csv`

每一行代表一条消费者评价。

| 字段名 | 中文含义 | 数据类型 | 示例 | 用途 |
|---|---|---|---|---|
| review_id | 评价编号 | 文本 | R001 | 唯一识别评价 |
| date | 评价日期 | 日期 | 2026-08-01 | 分析评价趋势 |
| platform | 电商平台 | 文本 | Tmall | 比较平台反馈 |
| sku_id | SKU编号 | 文本 | SKU001 | 关联商品 |
| rating | 评分 | 整数 | 4 | 判断用户满意度 |
| review_text | 评价内容 | 文本 | 味道不错，但包装有破损 | 提取评价主题 |

## 4. 核心指标定义

| 指标 | 计算方式 | 业务含义 |
|---|---|---|
| GMV | 单价 × 销售数量 | 商品销售总额 |
| 毛利 | （单价 − 单位成本）× 销售数量 | 销售产生的毛利润 |
| 毛利率 | 毛利 ÷ GMV | 判断商品盈利能力 |
| 广告ROI | GMV ÷ 广告费用 | 每投入1元广告带来的销售额 |
| 点击率 | 点击量 ÷ 曝光量 | 广告吸引力 |
| 转化率 | 订单量 ÷ 点击量 | 点击后产生购买的比例 |
| 退货率 | 退货数量 ÷ 销售数量 | 商品或履约质量风险 |
| 库存可售天数 | 当前库存 ÷ 日均销量 | 判断缺货和库存积压风险 |

## 5. 数据规则

- `sku_id`不能为空。
- 单价、成本、销量、库存和广告费用不能为负数。
- 评分范围为1到5。
- 点击量不能大于曝光量。
- 订单量不能大于点击量。
- 退货数量不能大于销售数量。
- 广告费用为0时，不直接计算广告ROI。
- 所有示例数据必须明确标注为模拟数据。
