# GrowthPilot 评估方案

## 1. 评估目标

GrowthPilot 的评估分为两部分：

1. 规则引擎能否准确识别经营风险。
2. AI 能否基于已有证据生成可执行、不过度推断的建议。

## 2. 测试场景

| 场景 | 预设异常 | 期望识别结果 |
|---|---|---|
| SKU001 | 最近7天销量明显下降 | 销量下降风险 |
| SKU003 | 广告费用上涨但销量增长有限 | 广告效率风险 |
| SKU004 | 库存可售天数过低 | 库存不足风险 |
| 正常SKU | 指标在合理范围内 | 不产生错误告警 |
